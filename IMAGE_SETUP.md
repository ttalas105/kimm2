## Supported Formats
- `.jpg` / `.jpeg`
- `.png`
- `.webp`

## Tips
- **Image Size**: Recommended width of 1200-2000px for best quality
- **File Size**: Compress images for faster loading (keep under 500KB each if possible)
- **Naming**: Use lowercase with hyphens (e.g., `luma-house.jpg`)

## If Images Don't Show
- Check that filenames match exactly (case-sensitive)
- Make sure images are in the `images/` folder
- Refresh your browser (Cmd+R or Ctrl+R)
- Check browser console for errors (F12)

## Customizing Image Names
If your images have different names, edit `script.js` and update the `images` arrays in the `projects` object.
